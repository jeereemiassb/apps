Export any Confluence table to Excel or CSV in one click.

Overview

Turn the tables on your Confluence pages and blog posts into spreadsheets without copying and pasting. The app reads the page with your own permissions and builds the file in your browser.

  • See every table on the page, with a preview and its size.
  • Download one table as Excel (.xlsx) or CSV.
  • Download all the tables as one Excel workbook, with one sheet per table named after the heading above it.
  • Choose how merged cells are handled and protect CSV files against formula injection.

Getting started

  1. A Confluence administrator installs the app from its Atlassian Marketplace listing.
  2. Open a page or blog post that contains a table.
  3. Open the More actions (•••) menu at the top of the page and select Export tables. Depending on your Confluence version, app actions can be grouped under an Apps entry in that menu.

Exporting tables

One table

The dialog lists every table on the page in order, with its size (rows × columns) and a preview of its first rows. Select Excel or CSV next to the table you want. The file is named after the page and the table.

All tables in one workbook

Select Download all (Excel, one sheet per table). Each sheet is named after the nearest heading above its table. Excel limits sheet names to 31 characters and does not allow some characters, so long or special names are shortened, and repeated names get a number.

Options

OptionWhat it does
Repeat merged cell valuesWhen a cell spans several rows or columns, its value is written in every cell it covers. When it is off (default), only the first cell gets the value and the others stay empty.
Protect CSV against formula injectionOn by default. Text cells that start with =, +, -, @ or a tab get an apostrophe in front, so spreadsheet programs show them as text instead of running them as formulas. It only applies to CSV files.

Moving from Table Exporter for Confluence

Atlassian ends support for Connect, the platform used by Table Exporter for Confluence, on 31 January 2027. This app is built on Forge and runs on Atlassian's cloud.

Nothing needs to be migrated: neither app stores data, they only read the tables of the page.

  1. Install this app from its Atlassian Marketplace listing.
  2. Open a page with tables and select Export tables in the More actions (•••) menu, where you used the other app's action.
  3. When you are happy with it, uninstall the other app.

Besides one table as Excel or CSV, this app downloads every table of the page as one Excel workbook, with one sheet per table.

Both apps can be installed at the same time, so you can try this one before you uninstall the other.

Limitations

  • Only tables written in the page are exported. Tables generated by macros, such as the Jira issues macro, are not included.
  • Cell text is exported; images, colours and formatting are not.
  • The app exports the published version of the page, not unpublished changes in the editor.

Permissions

ScopeWhy
read:page:confluenceRead the page to find its tables.
read:blogpost:confluenceRead blog posts to find their tables.

The page is read as the person exporting, so nobody can export a page they cannot read.

Data and privacy

The app stores nothing. The file is generated in your browser from data read inside Atlassian's cloud, and nothing is sent to any other server. See the privacy policy.

Troubleshooting

A table is missing from the list

It is probably generated by a macro (for example Jira issues or a page properties report). Those tables are built when the page is displayed and are not part of the page content.

The download does not start

Check that your browser allows downloads from your Atlassian site, then try again.

The app says it needs an active license

The app is paid and checks the license on every request. Ask your site administrator to check the app's subscription in the administration of Jira or Confluence (Apps → Manage apps). During a free trial the app works normally.
