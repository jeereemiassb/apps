Overview

Show CSV files on Confluence pages as tables readers can sort, search and page through.

  • From a .csv or .tsv file attached to the page, or CSV pasted in a code block inside the macro.
  • The separator (comma, semicolon, tab or vertical bar) is detected automatically, or you choose it.
  • Quoted values, and separators or line breaks inside cells, are read correctly.
  • Sort any column: numbers, dates and text each sort the right way, including numbers such as 1,234.50 or 1.234,50.
  • Search all cells, with several words at once.
  • Pages of 10 to 100 rows.

Getting started

  1. A Confluence administrator installs the app from its Atlassian Marketplace listing.
  2. Attach the CSV file to the page, or keep it ready to paste.
  3. Edit the page, type /CSV Table and insert the macro. With no settings, it shows the first .csv or .tsv attached; to paste the data instead, put it in a code block inside the macro.
  4. Publish the page.

Moving from CSV File To Table

Atlassian ends support for Connect, the platform used by CSV File To Table, on 31 January 2027. This app is built on Forge and runs on Atlassian's cloud.

Existing macros of the other app are not converted automatically. For each page:

  1. Keep the CSV file attached to the page.
  2. Type /CSV Table, insert the macro and name the file in Attachment if the page has more than one.
  3. Choose the Separator and whether the First row has the column names.
  4. Delete the old macro and publish.

Both apps can be installed at the same time, so you can try this one before you uninstall the other.

Limitations

  • Files up to 4 MB; the first 5,000 rows and 100 columns are shown.
  • Values are shown as text, without formulas or formatting.

Permissions

ScopeWhy
read:attachment:confluenceList the attachments of the page, as the person viewing it, to find the file.
readonly:content.attachment:confluenceDownload that file, as the person viewing the page.

No egress: the app does not connect to any server outside Atlassian.

Data and privacy

The app stores nothing. The file is read with the permissions of the person viewing the page and parsed in their browser. Nothing is logged and no data leaves Atlassian. See the privacy policy.

Troubleshooting

All the data is in one column

The separator was not detected: choose it in the macro settings.

The app says it needs an active license

The app is paid and checks the license on every request. Ask your site administrator to check the app's subscription in the administration of Jira or Confluence (Apps → Manage apps). During a free trial the app works normally.
