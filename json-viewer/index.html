Overview

Show JSON on Confluence pages the way readers need it: as a tree they can expand and search, or as formatted code with line numbers. If the JSON is not valid, the macro says exactly where the first error is.

  • A JSON Viewer macro for pages and blog posts.
  • Tree view: expand and collapse objects and arrays, choose how many levels open by default, expand or collapse everything.
  • Search keys and values; the tree shows only the matching branches.
  • Formatted view with line numbers.
  • Large numbers and repeated keys are kept exactly as written.
  • A JSON tools page to validate, format, minify or sort keys.

Getting started

  1. A Confluence administrator installs the app from its Atlassian Marketplace listing.
  2. Edit a page, type /JSON Viewer and insert the macro.
  3. Paste the JSON inside the macro, preferably in a code block, or into the JSON field of the macro settings.
  4. Publish the page. Readers see the tree and can switch to the formatted view.

Where the JSON comes from, in order: the JSON field of the settings, the first code block inside the macro, or all the text inside the macro.

JSON tools page

Open Apps → JSON tools in Confluence. Paste JSON and select Format (2 or 4 spaces, or tabs), Minify or View as tree. Sort keys orders the keys of every object alphabetically. Nothing you paste is stored.

Moving from JSON Viewer & Editor

Atlassian ends support for Connect, the platform used by JSON Viewer & Editor, on 31 January 2027. This app is built on Forge and runs on Atlassian's cloud.

Existing macros of the other app are not converted automatically. For each one:

  1. Edit the page and copy the JSON from the old macro.
  2. Type /JSON Viewer, insert the macro and paste the JSON inside it, in a code block.
  3. Choose Open as: Tree, or formatted code if the old macro showed code or text.
  4. Delete the old macro and publish.

To create, validate or format JSON, use the JSON tools page. Confluence administrators can see which pages use a macro in Confluence administration → Macro usage.

Both apps can be installed at the same time, so you can try this one before you uninstall the other.

Limitations

  • Up to 1,000,000 characters of JSON per macro.
  • The tree shows up to 800 lines at a time and large arrays show 100 items at a time; collapse parts or search to see the rest.
  • Comments, trailing commas and single quotes are not valid JSON and are reported as errors.

Permissions

The app asks for no Confluence permissions: it only reads the JSON inside its own macro.

Data and privacy

The app stores nothing. The JSON is parsed in the reader's browser, inside the page; the app's backend only checks the license. Nothing is logged and no data leaves Atlassian. See the privacy policy.

Troubleshooting

The macro says there is no JSON yet

Edit the page and paste the JSON inside the macro (in a code block) or into the JSON field of the macro settings.

Where exactly is the error?

The message gives the line and column of the first character that is not valid, and shows the lines around it with a mark under that column.

The app says it needs an active license

The app is paid and checks the license on every request. Ask your site administrator to check the app's subscription in the administration of Jira or Confluence (Apps → Manage apps). During a free trial the app works normally.
