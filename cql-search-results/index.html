CQL Search Results Macro for Confluence

Live results of a CQL query in any page, with the columns and order you choose.

Overview

Show the results of a CQL (Confluence Query Language) query in a Confluence page, as a table that is always up to date.

  • Any CQL query: by space, label, type, title, text, dates, contributors, ancestors and more.
  • currentSpace(), currentContent() and currentUser() work, so one macro can be reused in page templates.
  • Choose the columns: Title (with a link), Space, Type, Created by, Created, Last modified by, Last modified, Owner, Labels and Excerpt.
  • Sort by last modified, created or title, or keep the ORDER BY of your query.
  • 10, 25, 50 or 100 results per page, with Previous and Next.
  • An optional heading, your own message when nothing matches, and the query shown above the results if you want.
  • A CQL search page in the Apps menu to try queries before you put them in a page.
  • Every search runs with the permissions of the person reading the page: each reader only sees the content they can access.

Getting started

  1. A Confluence administrator installs the app from its Atlassian Marketplace listing.
  2. Edit a page, type /CQL Search Results and insert the macro.
  3. In the macro settings, enter a CQL query, for example space = currentSpace() AND label = "meeting-notes".
  4. Choose the columns, the sort order and the number of results per page.
  5. Publish the page.

Macro settings

SettingWhat it does
CQL queryThe query to run. Required. See Atlassian's CQL reference.
ColumnsTitle, Space, Type, Created by, Created, Last modified by, Last modified, Owner, Labels, Excerpt. Default: Title, Space, Created by, Last modified, Labels. If none is ticked, Title is shown.
Sort byAs in the query (its ORDER BY, or relevance if it has none) (default); Last modified, newest or oldest first; Created, newest or oldest first; Title, A to Z or Z to A. Any option other than the first replaces the ORDER BY of the query.
Results per page10, 25 (default), 50 or 100.
HeadingOptional heading shown above the results.
Message when nothing matchesOptional. Default: "No content matches this query."
Show the query above the resultsNo (default) or Yes. Shows the query that was run, including the sort order.

Example queries:

  • type = page AND space = currentSpace() ORDER BY lastmodified DESC — pages of this space, last changed first.
  • ancestor = currentContent() — everything under this page.
  • type = blogpost AND label = "release-notes" ORDER BY created DESC — release note blog posts, newest first.
  • type IN (page, blogpost) AND lastmodified >= now("-7d") — content changed in the last 7 days.
  • type = page AND contributor = currentUser() — pages the reader has contributed to (different for each reader).

CQL search page

Open Apps → CQL search. Enter a query, choose the sort order, the results per page and the columns, and select Search. The example buttons fill in common queries. The Excerpt column highlights the words that matched a text search (text ~ "..."). When the query works, copy it into a macro.

currentSpace() and currentContent() refer to the page that contains the macro, so they only work in the macro.

Moving from CQL Search

Atlassian ends support for Connect apps on 31 January 2027, and CQL Search is a Connect app. Macros of the other app are not converted automatically: each one has to be replaced once. For each page:

  1. Open the page in the editor and open the settings of the old macro. Copy its CQL query.
  2. Type /CQL Search Results, insert the macro and paste the query into CQL query.
  3. Match the old settings:

| Old setting | New setting | |---|---| | Number of results per page (10, 25, 50, 100) | Results per page (same values) | | Show Query | Show the query above the results | | Show Type / Space / Owner / Creator Column | Columns: Type / Space / Owner / Created by | | Show Created Date / Last Modifier / Last Modified Date / Labels Column | Columns: Created / Last modified by / Last modified / Labels |

  1. Delete the old macro and publish the page.

To find the pages that still use the old macro, try the query macro = "cql-query" in the CQL search page; if it returns nothing on your site, look for the pages by name. The old app's search screen is replaced by Apps → CQL search.

Limitations

  • Up to 100 results per page. Pages are browsed with Previous and Next; you cannot jump to a page number, because Confluence returns search results with a cursor.
  • The table cannot be re-sorted by clicking a column: use Sort by or ORDER BY in the query.
  • Content in archived spaces is not included.
  • Excerpts are cut at 300 characters.
  • Results come from Confluence's search index: a page edited a moment ago can take a short time to show its changes.
  • User fields in CQL (creator, contributor, mention, watcher) take account IDs or currentUser(), not usernames. This is a Confluence rule.
  • Author names are shown as Confluence returns them to the reader, following each person's profile visibility.

Data and privacy

The app stores nothing. The query and the settings are saved by Confluence in the page, like those of any other macro. The search runs with the permissions of the person viewing the page, and the results (titles, links, spaces, dates, labels, excerpts and the names of authors) are sent only to that person's page. Nothing is logged and no data leaves Atlassian. See the privacy policy.

Troubleshooting

"The CQL query is not valid"

The message below it comes from Confluence and says what it could not read. Common causes: a value with spaces without quotes (title = "Release notes"), a field that does not exist, or a username instead of an account ID or currentUser(). Try the query in Apps → CQL search until it works, then paste it into the macro.

"No content matches this query" but I expected results

Each reader only sees what they have permission to see, so two people can get different results. Content in archived spaces is not included. Check the query in the CQL search page.

currentSpace() does not work in the CQL search page

currentSpace() and currentContent() refer to the page that contains the macro. In the search page, name the space: space = "KEY".

"The results changed while you were paging"

The search cursor expired, for example after the page was left open for a long time. Select First page.

The app says it needs an active license

The app is paid and checks the license on every request. Ask your site administrator to check the app's subscription in the administration of Confluence (Apps → Manage apps). During a free trial the app works normally.
