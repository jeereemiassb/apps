Overview

A dashboard gadget that shows the recent activity of the issues in a saved filter or a JQL query, instead of a whole project.

  • Use any saved filter or write your own JQL.
  • Show issue creation, status changes, field changes, comments and work logged.
  • Watch only the fields you care about, by name or ID.
  • Limit the stream to certain people, choose the period and the number of items.

Getting started

  1. A Jira administrator installs the app from its Atlassian Marketplace listing.
  2. Open a dashboard, choose to add a gadget and search for Activity Stream by Filter / JQL.
  3. Add it and fill in the settings (below), then save.

Gadget settings

Reading the stream

Activity is listed from newest to oldest and grouped by day. Each item shows who did it, what changed, the issue key with a link, its summary and the time.

The gadget looks at up to the 100 most recently updated issues that match your query in the chosen period, and reads their history, comments and work logs with your permissions. When more activity matches than it can show, it says Showing the most recent items. Narrow the filter to see more.

Moving from Filters Activity Stream

Atlassian ends support for Connect, the platform used by Filters Activity Stream, on 31 January 2027. This app is built on Forge and runs on Atlassian's cloud.

Gadgets are not converted automatically. For each gadget of the other app:

  1. Add the Activity Stream by Filter / JQL gadget to the same dashboard.
  2. In Filter or JQL, write filter = 10001 with the ID of the saved filter the old gadget used, or paste its JQL.
  3. Choose the activity to show, and the people in Only these people if the old gadget was limited to some users.
  4. Remove the old gadget.

Both apps can be installed at the same time, so you can try this one before you uninstall the other.

Limitations

  • Up to 100 issues per refresh, and up to 90 days back.
  • Everyone sees only the issues they are allowed to see, so two people can see different streams on the same dashboard.

Data and privacy

The app stores nothing. The gadget settings are saved by Jira with the gadget. No data leaves Atlassian. See the privacy policy.

Troubleshooting

The gadget says the JQL query is not valid

Edit the gadget and test the same query in Jira's issue search.

A field change does not appear

Check the field name in the issue history, or use the field ID (for example customfield_10050).

The app says it needs an active license

The app is paid and checks the license on every request. Ask your site administrator to check the app's subscription in the administration of Jira or Confluence (Apps → Manage apps). During a free trial the app works normally.
